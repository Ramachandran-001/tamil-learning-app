# தமிழ்ப்பாதை — 10-ஆம் வகுப்பு தமிழ்

React மற்றும் Vite பயன்படுத்தி உருவாக்கப்பட்ட frontend கற்றல் தளம்.

## VS Code-ல் திறந்து இயக்குவது

1. ZIP-ஐ extract செய்து, அதிலுள்ள `studypath-tamil` folder-ஐ VS Code-ல் திறக்கவும்.
2. கணினியில் Node.js நிறுவப்பட்டிருக்க வேண்டும்.
3. VS Code Terminal-ல் `npm install` இயக்கவும்.
4. `npm run dev` இயக்கவும்.
5. Terminal காட்டும் உள்ளூர் முகவரியை உலாவியில் திறக்கவும் (பொதுவாக `http://localhost:3000`).

## Build

`npm run build` இயக்கினால் உற்பத்தி கோப்புகள் `dist` folder-ல் உருவாகும்.

## மாணவர் நிக் நேம் பட்டியல்

நிக் நேம் பட்டியல் browser `localStorage`-ல் சேமிக்கப்படுகிறது. அதே உலாவியில் மீண்டும் திறந்தால் பட்டியல் தெரியும்; வேறு மாணவர்களின் சாதனங்களுக்கு இது பகிரப்படாது. பலருக்கும் ஒரே பட்டியல் தேவைப்பட்டால் பகிரப்பட்ட தரவுச் சேமிப்பு சேவை இணைக்க வேண்டும்.

## உள்ளடக்கக் குறிப்பு

ZIP-ல் வழங்கப்பட்ட பாடநூல் PDF-கள் ஆதாரக் கோப்புகளாக உள்ளன. தற்போது உள்ள தமிழ் பாடத் தரவு எல்லா அதிகாரப்பூர்வப் பாடங்களையும் முழுமையாகக் கொண்டிருக்கிறதா என்பதை வெளியீட்டுக்கு முன் PDF-உடன் ஒப்பிட்டு சரிபார்க்கவும்.
